Privacy Policy for CosmicTelescope

Last updated: July 2026

In one sentence: CosmicTelescope does not collect, store, transmit, or share any personal data, because it does not connect to the internet at all.

CosmicTelescope ("the app") is an offline astrophysics and cosmology calculator developed by Pietro Bergamini. This policy explains what happens — and, more importantly, what does not happen — to your data when you use it.

Data collection

The app does not collect any personal data. Specifically, it does not:

  • Make any network requests. The app contains no networking code of any kind and has no permission to access the internet.
  • Use any analytics, advertising, or crash-reporting SDKs.
  • Collect device identifiers, advertising IDs, or usage statistics.
  • Request access to your location, camera, microphone, contacts, photos, or any other sensitive device data.
  • Create user accounts or require sign-in.

What stays on your device

All values you type into the app — redshifts, coordinates, telescope parameters, and so on — are kept only in the app's memory while you use it and are never written anywhere permanent, with one exception: a single small flag recording whether you've already dismissed the app's one-time onboarding tip. That flag is stored in the app's private, sandboxed storage on your device and never leaves it.

If you choose to export or share a plot from within the app, the image is written temporarily to the app's private storage and handed to your device's native share sheet — the same system dialog used by every other app — so that you can save it or send it wherever you choose. The app itself never transmits this file anywhere; it never has the ability to.

Third-party services

The app does not integrate with any third-party service, SDK, or API. Some result rows contain links that open your device's web browser to external astronomical data archives (for example MAST or the ESO Archive) only when you explicitly tap them; this policy does not cover those external sites, which have their own privacy policies.

Children's privacy

The app is not directed at children and is not designed to collect information from anyone, regardless of age. Since no data is collected from any user, no data is collected from children either.

Changes to this policy

If this policy ever changes — for example, if a future version of the app adds a feature that requires network access — this page will be updated and the "Last updated" date above will reflect the change.
